# Progetto di Laboratorio di Algoritmi

Testo della consegna riscritto in forma chiara

## Esercizio 1: Gestione delle chiavi duplicate in un ABR

**Obiettivo.** Confrontare tre strategie per gestire chiavi duplicate in un albero binario di ricerca (ABR):

1. **Implementazione standard**, senza accorgimenti particolari per i duplicati.
2. **Implementazione con flag booleano** in ciascun nodo.
3. **Implementazione con lista di nodi**, in cui i nodi con la stessa chiave vengono mantenuti in una lista.

**Attività richieste.**

- Scrivere programmi Python (non notebook) che implementino le tre varianti e che eseguano una serie di test che permettano di individuare vantaggi e svantaggi di ciascuna.
- Progettare ed eseguire esperimenti adeguati, analizzandone i risultati.
- Redigere una relazione in LaTeX che descriva il lavoro svolto, seguendo le indicazioni presenti nella pagina Moodle del corso.

**Vincolo.** Le strutture dati devono essere implementate direttamente nel progetto: non è consentito usare librerie sviluppate da terzi né copiare codice altrui.

## Esercizio 2: Confronto tra algoritmi di ordinamento

**Obiettivo.** Confrontare gli algoritmi di ordinamento **selection sort** e **quicksort**, evidenziandone vantaggi e svantaggi.

**Attività richieste.** Realizzare un notebook Jupyter che:

- generi i dati di test, in modo che esecuzioni diverse producano dati diversi;
- esegua i test e produca i risultati;
- contenga, in celle Markdown al suo interno, sia la documentazione del codice sia la descrizione degli esperimenti.
